**0. 건축·인프라·교통의 기본 원칙**

인역의 건축물, 인프라, 교통 체계는 모두 영기공학(靈氣工學)이라는 단일한
기술 체계 위에서 성립한다. 영기를 어떻게 공급·순환·소비하느냐가 모든
구조물의 기능 수준을 결정하며, 영원(靈源)과의 거리가 곧 문명 수준의
격차를 만든다.

+-----------------------------------------------------------------------+
| 【이 설정집의 범위】                                                  |
|                                                                       |
| 본 문서는 Lv.0~Lv.3 중저레벨 기술로 건설·운용·유지 가능한 모든       |
| 구조물을 다룬다.                                                      |
|                                                                       |

**0-1. 4대 설계 제약**

인역의 모든 구조물은 아래 네 가지 제약을 동시에 만족해야 한다. 어느
하나를 우회하는 설계는 6대 법칙 위반이다.

  -----------------------------------------------------------------------
  **제약**           **내용**
  ------------------ ----------------------------------------------------
  의식 연결점 필수   모든 영문 구조물에는 운용자의 의식이 개입하는 지점이
                     반드시 존재한다. 완전 자동 운용 불가.

  영기 공급 의존     구조물은 외부 영기 공급이 끊기면 즉시 정지한다. 자체
                     영구 구동 불가(피드백 루프 효율 최대 80%).

  등급별 제작 레벨   구조물의 등급은 제작자의 레벨에 의해 상한이
                     결정된다. 레벨 이상의 구조물 제작 불가.

  유지·보수 필요     모든 영문 구조물은 시간이 지남에 따라 각인이
                     희미해지며, 주기적 점검·재각인이 필요하다.
  -----------------------------------------------------------------------

**0-1-1. 각인의 잔류 의지 (殘留意志)**

영문 각인에는 각인자의 의지가 주입되며, 그 의지는 각인이 물리적으로
희미해진 뒤에도 회로 구조에 잔류한다. 잔류 의지는 즉시 소멸하지 않고
**시간차를 두고 되돌아온다** --- 재각인이나 설정 변경을 가한 지점에서
당장은 반응이 없다가, 수 시간에서 수일 뒤 계통 말단에서 압력 변동·출력
이상으로 발현하는 것이 대표적 양상이다.

  -----------------------------------------------------------------------
  **특성**           **내용**
  ------------------ ----------------------------------------------------
  지연 발현          변경 시점과 발현 시점이 분리된다. 지연 폭은 계통
                     규모·도관 노후도·각인 누적 횟수에 좌우되며 일반
                     공식이 성립하지 않는다.

  누적성             재각인 이력이 많은 구간일수록 잔류 의지가 겹쳐
                     쌓인다. 시공 시기가 다른 구간이 한 계통에 묶여 있을
                     때 특히 강하게 나타난다.

  측정 한계          탐침으로 검출되지 않는 경우가 많다. 직접 접촉 감각
                     또는 시간축 기록 대조로만 확인되는 사례가 다수다.

  비가역성           제거할 수 없다. 설계 단계에서 지연을 감안해 대응하는
                     것 외의 해법이 없다.
  -----------------------------------------------------------------------

> 이 현상은 제2법칙(의식 선행)의 직접적 귀결이다. 영기가 의식의 주도로
> 움직이는 이상, 주입된 의지는 각인의 물리적 수명과 별개로 계통에 남는다.

**0-1-2. 시간축 병행 기록 (時間軸倂行記錄)**

잔류 의지에 대응하기 위해 정착된 점검 절차. 계통 이상을 위치별로만
기록하지 않고 **시간순으로 병행 기록**하여, 서로 떨어진 구간의 이상이
동일 원인에서 비롯된 것인지를 판별한다. 현재력 810년대에 관리국 인프라
시설과의 표준 절차로 채택되었으며 3등급 이상 연쇄문 조사에 준용된다.

**0-1-3. 선폐후개 절차 (先閉後開節次)**

특정 계보가 정립한 작업 방법론으로, **인역 전체의 강제 규범은 아니다.**
세력마다 다른 방식을 쓰며(철령원 공사는 내부 조사 완료 후 공개하는 방식을
오래 유지했다), 이 절차는 그에 대한 대안으로 제시된 계보에 속한다.
말원 조성을 이끈 한이령 일파의 방식으로 전하며, 명칭은 후대의 정리다 ---
정립자 본인은 \'닫는 법을 먼저 만든다\'고만 말한 것으로 전해진다.

  -----------------------------------------------------------------------
  **원칙**           **내용**
  ------------------ ----------------------------------------------------
  ① 선폐후개         비상 차단·재봉인 구조를 본체 구조보다 **먼저**
                     설계·설치한다. 되돌릴 수단이 갖춰지기 전에는 열지
                     않는다.

  ② 표지 병기        기존 봉인 표지를 제거하지 않고 재개 표기를 병기한다.
                     닫은 이유를 지우지 않아야 다음 사람이 판단할 수 있다
                     (3-7항).

  ③ 삼중 대조        계기 수치·청진 도구·직접 감각 판단을 병행 대조한다.
                     어느 하나가 다른 둘과 어긋나면 그 불일치 자체를 이상
                     신호로 기록한다.

  ④ 감각 판단자 배치 수치로 잡히지 않는 이상을 감지할 인력을 절차상 상시
                     배치한다. 계기는 정상인데 직접 감각만 이상을 포착한
                     사례가 근거다.

  ⑤ 미상 기재        원인을 모르는 것은 모르는 대로 기재한다. 가정과 감정은
                     기록에 남기지 않되, 확인되지 않았다는 사실 자체를
                     지우지 않는다.

  ⑥ 조작권 개방      해당 설비를 다루는 사람 누구나 차단 구조를 조작할 수
                     있도록 교육하고 표기한다. 정지 권한이 판단자 한 사람에게
                     집중되지 않게 한다.
  -----------------------------------------------------------------------

> 규범이 아니라 방법론이므로, 프로덕션에서 이 절차를 따르지 않는
> 조직·인물을 그리는 것은 정합성 위반이 아니다.

**0-1-4. 환경 영기의 직접 집적 --- 채산성 문제**

인역 공간에는 영기가 편재하지만(세계관 설정집 3항 편재성), 그것을 설비로
직접 끌어모아 인프라 동력으로 쓰는 방식은 인역 어디에도 정착하지 않았다.
**원리적으로 금지된 것이 아니라 채산이 맞지 않기 때문이다.**

  -----------------------------------------------------------------------
  **제약**           **내용**
  ------------------ ----------------------------------------------------
  ① 밀도             인역은 저영기 안정 구역이며 환경 영기는 \'희박하게
                     존재\'하는 수준이다. 거점 하나를 돌릴 양을 모으려면
                     도관 연결 비용을 크게 웃도는 집적 면적과 시간이
                     필요하다. 영원 근처에서는 애초에 도관을 끌어오는
                     편이 싸고, 영원에서 멀수록 환경 밀도도 함께 낮아져
                     집적 효율이 더 떨어진다. **필요한 곳일수록 불리하다.**

  ② 인력             영문 구조물은 공급받는 구조이지 수집하는 구조가
                     아니다(0-1 영기 공급 의존). 희박한 영기를 능동적으로
                     끌어모으는 작업에는 의식 연결점이 필요하므로
                     (제2법칙) 무인 운용이 불가하고 상시 인력이 붙어야
                     한다. 산출량 대비 인건비가 도관 연결이나 축령정
                     운반보다 높다.

> 무엇이 일어나는가」 참조.

**3-6. 구 정착로 (舊定着路) --- 등급 밖의 옛길**

현행 3등급 체계에 포함되지 않는 네 번째 범주. 도관망이 완비되기 이전,
영원과 무관하게 지형과 도보 경로만으로 형성됐던 정착지 간 통로다.

  -----------------------------------------------------------------------
  **항목**           **내용**
  ------------------ ----------------------------------------------------
  성격               현재의 도관 체계보다 오래된 지리를 따른다. 도관망
                     완비 이후 공식 경로에서 제외되어 대부분 지도에서
                     사라졌다.

  현재 상태          일부 구간만 지역 구전으로 위치가 전해진다. 다수
                     지역에서 \'함부로 다니지 않는다\'는 금기 형태로만
                     기억이 잔존한다.

  기록 상태          공식 문서에는 \'구 정착로는 도관망 완비 이후 공식
                     경로에서 제외됨\' 수준의 한 줄 요약만 남아 있는
                     경우가 많다. 자연스러운 폐기인지 의도적 배제인지는
                     문서상 판별되지 않는다.

  설정상 중요성      침식 격리 표지(3-7항)가 도관망이 아니라 이 옛길을
                     따라 배치되어 있다. 옛길을 아는 것이 표지 체계를
                     읽는 전제 조건이다.
  -----------------------------------------------------------------------

**3-7. 침식 격리 표지 (浸蝕隔離標識)**

침식 위험이 확인된 구간을 폐쇄하면서 남기는 표기 체계. 폐쇄 자체가
아니라 **폐쇄한 이유와 위험 등급을 후대에 전달하는 것**이 목적이다.

  -----------------------------------------------------------------------
  **항목**           **내용**
  ------------------ ----------------------------------------------------
  기본 형태          원(圓) 안에 짧은 선을 새긴 문양. 도관 접속부·봉인관
                     입구·옛길 분기점 등에 각인된다.

  등급 표기          원 안의 선 개수가 격리 등급을 나타낸다(예: 3개와
                     4개가 서로 다른 등급). 등급 기준을 정한 주체와 각
                     등급의 정확한 의미는 현행 문서에 남아 있지 않다.

  잔류 반응          마모가 심한 표지에서도 직접 접촉 시 희미한 영기
                     잔류 반응이 감지되는 사례가 보고된다. 원인 미규명.

  재개 시 원칙       봉인을 해제하고 관을 재개할 때 기존 표지를 제거하지
                     않고 재개 표기를 병기하는 것이 확립된 실무 관행이다
                     --- 닫은 이유를 지우지 않아야 다음 사람이 판단할 수
                     있기 때문이다.
  -----------------------------------------------------------------------

> 이 표지 체계는 경계각문 계통의 말단 파편으로 추정된다(언어·문자
> 설정집 7항 참조). 다만 표지를 새긴 주체와 시기는 확인되지 않았다.

영원 도시 · 거점 도시 · 변방 정착지 설계 원리

**4-1. 도시 형성 원리**

인역의 도시는 예외 없이 영원(靈源)을 중심으로 형성된다. 영원의 규모가
도시의 최대 크기와 기술 수준을 결정하며, 영원에서 멀어질수록 영기 밀도와
기술 수준이 동심원 형태로 저하된다.

+-----------------------------------------------------------------------+
| 【도시 성장의 원리】                                                  |
|                                                                       |
| 도시는 영원 위에 세워지는 것이 아니라, 영원에서 뻗어나온 영기         |
| 맥(靈氣脈)을 따라 확장된다.                                           |
|                                                                       |
| 영기 맥이 지나는 방향으로 도관망을 연장하는 것이 가장 효율적이므로,   |
|                                                                       |
| 인역의 도시들은 방사형보다 영기 맥 경로를 따른 선형·비대칭형 확장이   |
| 더 흔하다.                                                            |
+-----------------------------------------------------------------------+

**4-2. 도시 구조 --- 수직·수평 격차**

사이버펑크적 계층 구조와 선협적 영기 수련 환경이 결합된 것이 인역 도시의
특징이다. 영기 인프라 접근성이 거주 계층을 결정하며, 물리적 고도가 영기
밀도와 반드시 비례하지 않는다.

|                                                                       |
| 1\. 모든 구조물에는 반드시 의식 연결점이 있다. 완전 자동화는 없다.    |
|                                                                       |
| 2\. 모든 영기 설비는 외부 공급이 끊기면 정지한다. 영구 구동 설비는    |
| 없다.                                                                 |
|                                                                       |
| 3\. 영문 구조물의 등급은 제작자 레벨이 상한을 결정한다.               |
|                                                                       |
| 4\. 모든 구조물은 시간이 지남에 따라 노후화되며, 유지·보수 비용이     |
| 발생한다.                                                             |
|                                                                       |
| 5\. 지역 격차는 영원 접근성이 직접 만들며, 이것이 인역 내 모든 사회적 |
| 불평등의 물질적 기반이다.                                             |
