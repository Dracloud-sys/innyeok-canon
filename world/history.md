시대이며, 어떤 해석도 \'정설\'로 확정된 바 없다.

태고기 이후 언제부터 인간이 인역에 존재했는지는 확인되지 않는다. 현재
문명이 \'원시 문명기\'라고 부르는 것은 분산된 마을 단위 집락들이
중원대지와 영기 맥 주변에 형성된 것으로 추정되는 시기다. 이 시기의
인간들이 영기를 어떻게 인식했는지는 두 가지 사료가 단서를 제공한다.

**2-1. 최초의 영기 각인 --- \'감응의 시대\'**

+-----------------------------------------------------------------------+
| **◈ 최초의 영문 각인에 관하여**                                       |
+-----------------------------------------------------------------------+
| 원시 문명기 유물 중 가장 이른 것은 천극산맥 동부 동굴에서 발견된      |
| \'원초각(原初刻)\' --- 현재 1등급 영문에 대응하는 단순 반복 동작      |
| 패턴의 각인이다.                                                      |
|                                                                       |
| 이 각인들은 설계된 것이 아니라 영기에 노출된 인간이                   |
| 의식적·무의식적으로 새긴 흔적으로 해석된다. 당시 인간의 Lv.1 수준     |
| 영기 각성이 이미 이루어졌음을 시사.                                   |
|                                                                       |
| 마수 장로 구전에는 이 시기를 \'인간이 영기를 두려워하면서도 흉내 내기 |
| 시작한 때\'로 묘사하는 표현이 등장한다.                               |
|                                                                       |
| *※ 이 시기는 \'의식이 영기를 먼저 다루었는가, 영기가 의식을           |
| 형성했는가\'라는 제2법칙의 근원 논쟁과 연결된다.*                     |
+-----------------------------------------------------------------------+

**2-2. 원시 공동체와 마수 --- 최초의 공존과 충돌**

이 시기의 인간 집락 유적에서 공통적으로 발견되는 것이 마수의 영기
흔적이다. 완전히 적대적이지 않은 방식의 마수 출입 흔적이 일부 유적에서
나타나며, 인역 최초의 \'공존 시도\'가 이 시기에 이루어졌다는 해석이
있다. 한편 같은 시기 유적에 대규모 영기 충돌 흔적도 존재하여, 공존과
충돌이 동시에 일어났음을 보여준다.

+-----------------------------------------------------------------------+
| **◆ 미해결 논쟁 이 시기 고레벨 마수는 인간을 어떻게 인식했는가?**     |
+-----------------------------------------------------------------------+
| **[해석 1] 무관심설 --- 당시 인간은 Lv.0~1 수준, 마수에게 위협이   |
| 아니었다**                                                            |
|                                                                       |
| > *근거: 충돌 흔적의 규모가 작고 일방적. 고레벨 마수가 의도적으로     |
| > 개입했다면 집락 자체가 남지 않았을 것.*                             |
+-----------------------------------------------------------------------+
| **[해석 2] 관찰·이용설 --- 일부 고레벨 마수가 인간의 영기 각인      |
| 기술을 흥미롭게 관찰**                                                |
|                                                                       |
| > *근거: 녹령원 장로 구전에 \'작은 것들이 돌에 선을 새기는 것을       |
| > 지켜보았다\'는 표현. 현재 마수-인간 공존의 최초 씨앗.*              |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **3부 암흑기 (暗黑期)**                                               |
|                                                                       |
| *현재력 -500 ~ -1년 추정 · 대침식 사건과 재건*                       |
+-----------------------------------------------------------------------+

암흑기는 인역 역사에서 가장 극적인 단절 구간이다. 원시 문명기의 집락들이
어느 시점에 대규모로 붕괴되었으며, 그 원인으로 지목되는 것이 \'대침식
사건(大浸蝕事件)\'이다. 사료가 극히 드물어 정확한 연대와 원인은 여전히
논쟁 중이지만, 현재 문명이 침식을 두려워하는 문화적 배경에는 이 시기의
집단 기억이 깔려 있다.

**3-1. 대침식 사건 (大浸蝕事件)**

+-----------------------------------------------------------------------+
| **▲ 대침식 사건 개요**                                                |
+-----------------------------------------------------------------------+
| 발생 추정 시기: 현재력 -300 ~ -200년 사이 (연대 논쟁 중)             |
|                                                                       |
| 현상: 인역 북부에서 시작된 것으로 추정되는 대규모 침식 확산. 경계대   |
| 인근 문명 집락 대부분이 수십 년 이내에 소멸하거나 이탈.               |
|                                                                       |
| 생존 집락: 중원대지 중심부와 남부평원 일부만 침식 영향권에서 벗어난   |
| 것으로 추정.                                                          |
|                                                                       |
| 원인 미규명: \'외부 세계와의 차원 경계가 일시적으로 약화되었다\'는    |
| 설과 \'당시 레벨 고위자가 Lv.6에 근접하면서 세계 부하를 일으켰다\'는  |
| 설이 병존.                                                            |
|                                                                       |
| *※ 대침식 사건은 현재 영원 맹약이 \'차원 경계 유지\'를 최우선         |
| 명분으로 내세우는 역사적 근거이기도 하다.*                            |
+-----------------------------------------------------------------------+

**3-2. 암흑기 재건 --- 영기 수련의 체계화 시작**

대침식 이후 살아남은 집락들은 두 가지 공통된 방향으로 수렴했다. 첫째,
영기를 더 잘 다루어야 살아남는다는 실존적 동기. 둘째, 침식에 저항하려면
의식 수준을 높여야 한다는 경험적 발견. 이 두 압력이 영기 수련의 체계화를
가속했으며, 이 시기에 레벨 개념의 원형이 수련 집단 내에서 형성되기
시작했다.

+-----------------------------------------------------------------------+
| **◆ 암흑기가 남긴 문화적 유산**                                       |
+-----------------------------------------------------------------------+
| 암흑기 재건 시기의 가장 중요한 문화적 유산은 \'침식을 겪고도 의식을   |
| 유지한 자\'에 대한 경외감이다.                                        |
|                                                                       |
| 이것이 현재 레벨 시스템, 특히 \'의식 수준\'을 세 축 중 가장 중요하게  |
| 여기는 문화로 이어졌다.                                               |
|                                                                       |
| 남원 집거의 창립 신화가 이 시기 생존자 중 가장 높은 의식 수준을       |
| 보유한 집단에서 기원한다는 설이 있다.                                 |
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| **4부 발흥기 (發興期)**                                               |
|                                                                       |
| *현재력 1 ~ 200년 · 영기공학 체계화와 최초 도시*                     |
+-----------------------------------------------------------------------+

발흥기는 현재 문명 체계의 진짜 출발점이다. 현재력 원년은 영기공학의 핵심
개념인 \'영문(靈紋)의 등급 체계\'가 최초로 문자로 정리된 해로 정의된다.
이후 200년간 인역 문명은 고대 이후 최대의 도약을 이룬다.

|                                                                       |
| 이 연대기는 특정 \'현재\' 시점을 고정하지 않는다. 모든 사건은 현재력   |

이 시기는 격동기에 성립된 구도가 고착되면서 동시에 그 균열이 가시화되는
시기다. 어떤 세력도 인역 전체를 지배하지 못하고, 어떤 세력도 완전히
패배하지 않은 채 수십 년이 흘렀다. 그러나 두 가지 사건이 이 균형을
흔들고 있다 --- 영기공학의 누적 발전으로 인역의 수용 한계가 서서히
상승하고 있으며, 처음으로 Lv.6 가능성이 현실의 문제로 대두되고 있다.
