**0. 기본 원리**

인역(人域)의 기술 체계는 현실 세계의 전기·화학·기계 공학 대신 영기
회로(靈氣回路)와 영문(靈紋)을 중심으로 발전했다. 이를
영기공학(靈氣工學)이라 총칭한다.

영기공학이 인역 문명의 기반인 이유는 두 가지다. 첫째, 영기는 인역 공간
내 어디에나 희박하게 편재하며 적절한 구조물을 통해 수집·운용할 수 있다.
둘째, 영기는 의식이 있는 존재라면 Lv.0조차 도관망을 통해 간접적으로
수혜를 받을 수 있다. 이 두 특성이 결합되어 인역 문명 전체를 영기공학
기반 사회로 만들었다.

+-----------------------------------------------------------------------+
| 【의식 선행 법칙 --- 기술 전반에 적용되는 핵심 제약】                 |
|                                                                       |
| 영기는 반드시 의식의 주도 하에 운용된다. 완전 자동화는 불가능하다.    |
|                                                                       |
| 영문 구조물은 설계된 패턴 내에서만 반복 작동하며, 예외 상황           |
| 판단·학습·창의적 대응은 전혀 불가능하다.                              |
|                                                                       |
| 모든 구조물에는 반드시 운용자의 의식이 개입하는 지점(의식 연결점)이   |
| 존재하며,                                                             |
|                                                                       |
| 이 지점에서 사람이 개입하지 않으면 구조물은 정지하거나 설계값만       |
| 반복할 뿐이다.                                                        |
+-----------------------------------------------------------------------+

운용·유지·설계는 각성 이상의 개체만 담당할 수 있다.

**3-5. 이동 수단**

인역의 이동 수단은 영기 인프라 접근성에 따라 극적인 차이를 보인다.
공백지와 영원 도시 간의 이동 속도 차이는 현실의 도보와 고속열차
수준이다.

  -----------------------------------------------------------------------
  **이동 수단**      **레벨**     **특성**
  ------------------ ------------ ---------------------------------------
  도보·마차          Lv.0         영기 구동 없음. 마수 출몰 지역 통행
  (공백지·변방)                   위험. 이동 속도 느림

  영기 구동 소형     Lv.1 운용    축령정 구동. 마차보다 2~3배 빠름. 오지
  차량 (변방)                     지형에서 운용 한계

  영기 구동 대형     Lv.1~2      도관 충전 또는 축령정. 물자 대량 운송
  차량 (거점)                     가능. 탐사대 이동

  도시 내 영기 차량  Lv.1 운용    도시 내 도로 기반. 도관 충전 정류소
  (거점·영원)                     사용. 자동화 경로 일부

  영기 궤도열차 靈軌 Lv.2+ 운용자 도시 간 고속 이동. 경로 주행만 자동화.
  (도시 간)          탑승 필수    출발·정차·비상은 운용자 개입 필수. 무인
