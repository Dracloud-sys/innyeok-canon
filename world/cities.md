| 독립적이라는 주장의 물리적 반증                                       |
|                                                                       |
| 지하 구획 봉인 구역에 대한 정보 통제: 무흔 일부 결절이 지하 접근을    |

|                                                                       |
| 공사 Lv.5 원수의 실제 건강 상태: 원수루 특구 출입이 점점 제한되면서   |
