# 人域 인역 Lv.4~5 고급 기술 체계 설정집
*경계인·극한자 기술 레퍼런스* v1.0 │ 세계관 설정집 v4 완전 정합

---

## 0. 문서 개요

이 설정집은 인역(人域) 내에서 Lv.4(경계인)~Lv.5(극한자) 수준의 존재만이 운용·건설·생산할 수 있는 기술 전반을 다룬다. Lv.0~3 기술이 인역 문명의 일상을 구성한다면, Lv.4~5 기술은 문명의 한계와 외부 세계 사이의 경계를 다루는 영역이다. 이 단계의 기술은 더 이상 '더 효율적인 도구'가 아니라 '존재의 질적 변화'와 결부된다.

| 구성 | 내용 | 핵심 용도 |
|---|---|---|
| 1. 존재 정의 | Lv.4·5 정의 및 질적 차이 | 레벨별 능력 기준·서사 스케일 설정 |
| 2. 술식 체계 | Lv.4~5 전용 술식 명세 | 전투·탐사 술식 설계 레퍼런스 |
| 3. 건축·인프라 | 5등급 영기 건축 체계 | 차원 경계 시설·극한 수련 공간 설계 |
| 4. 소재·생산 | Lv.4~5 전용 소재 및 조달 | 고급 소재 체계·접근 불평등 설계 |
| 5. 영체·의식 결정 | 사후 메커니즘·결정 등급 | 고레벨 존재의 생사 경계 서사 |
| 6. 외부 세계 운용 | 경계 탐사·전투·귀환 기술 | 외부 세계 파트 서사 설계 |
| 7. 세력별 기술 독점 | 세력별 고급 기술 분포 | 세력 갈등·독점 서사 설계 |
| 8. 한계·실패·부작용 | 고급 기술의 위험성 | 갈등 요소·현실감 부여 |

> ※ 이 문서의 모든 기술은 **의식 선행 법칙(제2법칙)**에 의거한다. Lv.4~5 기술이 Lv.0~3 기술과 근본적으로 다른 이유는 운용자의 의식 수준이 기술의 구조 자체에 영향을 미치기 때문이다. 단순히 출력이 높아지는 것이 아니라, 영기 조작의 원리가 달라진다.

## 1. 존재 정의 — 경계인과 극한자

### 1-1. Lv.4 경계인 (境界人)

인역과 외부 세계의 경계를 '인식'할 수 있게 되는 존재적 전환점. 영기 조작의 규모와 정밀도가 Lv.3와 질적으로 다른 차원에 위치하며, 인역 인구의 1% 미만을 차지하는 극소수 특수 전력이다.

| 항목 | 내용 |
|---|---|
| **핵심 전환** | 의식 수준이 '경계 인식' 임계를 돌파. 외부 세계를 공허한 미지(未知)가 아닌 '실재하는 구조'로 인식하기 시작. |
| **영기 조작** | 영역 전개 가능 — 자신 중심 반경 내 영기 흐름을 지배하에 둠. 타인의 영기 운용 효율을 능동적으로 저하시킬 수 있다. |
| **사후 처리** | 사망 시 육체가 소멸해도 영체(靈體)가 잔존. 의식·인식·일부 영기 조작이 가능한 상태로 수일~수개월 유지 가능. |
| **사회적 위치** | 인역 내 특수 전력의 최하단. 세력 고위 간부·외부 세계 탐사 주력. Lv.4 인증은 인역 내 최고 공식 인증 절차 중 하나. |
| **전환 조건** | 재능·향상심·기연 세 조건 모두 필요. 의식 수준이 절대적 병목 — 영기 축적량이 아무리 높아도 의식 임계 미달이면 경계인이 될 수 없다. |
| **인구 비중** | 인역 전체 인구의 1% 미만. 각 영원 도시에 수십~수백 명 수준. 대부분 세력에 소속되어 있으며 개인 활동은 드물다. |

### 1-2. Lv.5 극한자 (極限者)

인류 종이 도달 가능한 영기 축적·육체·의식 수준의 극점. '더 강해지는 것'이 아니라 '존재 방식이 달라지는 것'에 해당하는 전환. 역사상 극소수만이 도달했으며, 현재 인역에서 확인된 Lv.5 존재는 손에 꼽는다.

| 항목 | 내용 |
|---|---|
| **핵심 전환** | 외부 세계를 '인식'하는 것을 넘어 외부 세계에서의 자신의 존재를 '확신'하는 단계. 존재 자체가 영기 압력원이 된다. |
| **존재 압력** | 의도적 술식 없이 존재 자체에서 영기 압력이 발생. 저레벨 존재의 영기 운용을 자동으로 억제. 아군에게도 영향을 미치므로 단독·소수 정예 운용이 원칙. |
| **영기 도메인** | 대규모 영역 내 영기 흐름을 전면 장악. 군단 규모의 영향력 행사 가능. Lv.4의 영역 전개와 달리 능동 술식 없이도 유지된다. |
| **국가급 전력** | 단독으로 군사 작전 수행 가능. 세력의 최고 자산이자 최대 약점 — Lv.5 존재의 죽음은 세력 권력 구조 전체를 흔든다. |
| **전환 조건** | 외부 세계 인식 확립(Lv.4 숙련) + 자기 확신. 외부 세계에서의 극한 경험 없이는 불가에 가깝다. Lv.4 안착 후 수십 년이 일반적이며 일부는 평생 문 앞에 선다. |
| **인구 비중** | 역사상 극소수. 현재 인역에서 공식 확인된 Lv.5는 남원 집거 내부 추정 포함 10인 미만으로 알려짐. 은밀하게 활동하거나 세력 내부에 격리된 경우 多. |

### 1-3. Lv.4와 Lv.5의 결정적 차이

| 구분 | Lv.4 경계인 | Lv.5 극한자 |
|---|---|---|
| **영기 조작** | 능동 술식으로 영역 제어 | 존재 자체가 영역을 구성 |
| **전투 규모** | 소대~중대 수준 영향력 | 군단 규모 영향력 |
| **외부 세계** | 인식 가능 + 탐사 가능 | 외부 세계에서도 압도적 주도권 |
| **팀 운용** | 팀 전투 정상 참여 | 단독·소수 정예 필수 (존재 압력 부작용) |
| **영체 잔존 지속력** | 수일~수개월 | 수년~수십 년 가능 |
| **의식 결정 형성** | 수십 년 이상 수련 후 가능(하급~중급) | 상급 의식 결정 형성 가능 |
| **사회적 공개 여부** | 인증 시스템으로 공식 관리 | 대부분 비공식·은밀. 세력 기밀 자산 |

## 2. 술식 체계 — Lv.4~5 전용 술식

Lv.4 이상의 술식은 단순히 출력이 높은 Lv.3 술식의 연장이 아니다. 운용자의 의식 수준이 술식 구조 자체에 개입하며, 동일한 술식이라도 경계 인식의 깊이에 따라 효과 범위와 안정성이 달라진다. Lv.5의 일부 술식은 '의도적 발동'이 아닌 '존재 방식'에 가깝다.

### 2-1. Lv.4 전용 술식

| 술식명 | 한자 | 최소 레벨 | 효과 및 특성 |
|---|---|---|---|
| **영역 전개** | 靈域展開 | Lv.4 | 자신 중심 일정 반경을 영기 지배 영역으로 설정. 범위 내 타인 영기 운용 효율 대폭 저하. 범위와 밀도는 의식 수준에 비례. |
| **영체 분리 공격** | 靈體分離擊 | Lv.4 | 일부 의식을 영체 형태로 분리하여 원격 공격 수행. 본체는 방어·이동에 집중 가능. 분리 시간 비례로 본체 방어력 저하. |
| **차원 경계 인지** | 次元境界認知 | Lv.4 | 인역과 외부 세계 경계 구조를 실시간으로 인식. 탐사·경계 유지 작업의 기반 기술. 경계 약화 지점 탐지 가능. |
| **의식 방어막** | 意識防禦幕 | Lv.4 | 정신 침식·의식 공격 차단. 외부 세계 탐사 시 의식 유지를 위한 핵심 방어술. 침식종의 정보 오염 경로를 차단. |
| **고밀도 영기 압축** | 高密靈氣壓縮 | Lv.4 | 영기를 임계 밀도 이상으로 압축하여 집중 방출. Lv.3 술식의 수배 출력 가능. 과압축 시 술식 폭주 위험. |
| **영기 흡수 역류** | 靈氣逆流 | Lv.4 | 상대방 또는 주변 환경의 영기를 역방향으로 흡수. 회복·강화 겸용. 침식 영기 흡수 시 자신도 오염 위험이 있어 의식 방어막 필수. |
| **공간 각인술** | 空間刻印術 | Lv.4 | 공간의 특정 지점에 영기 구조를 고정 각인. 5등급 영기 건축의 핵심 기반 기술. 인역 내에서도 자격 보유자만 사용 가능. |

### 2-2. Lv.5 전용 술식

| 술식명 | 한자 | 최소 레벨 | 효과 및 특성 |
|---|---|---|---|
| **영기 도메인** | 靈氣領域 | Lv.5 | 대규모 영역 내 영기 흐름 전면 장악. 군단 규모 영향력. Lv.4 영역 전개와 달리 지속 능동 유지 불필요. 도메인 내 모든 영기 현상을 인식·조작. |
| **존재 압력** | 存在壓力 | Lv.5 | 술식이 아닌 존재 자체에서 발생하는 현상. 저레벨 존재의 영기 운용 자동 억제. 아군에게도 영향을 주므로 대규모 팀 전투에서 역효과 발생. |
| **차원 경계 조작** | 次元境界操作 | Lv.5 | 차원 경계 구조에 직접 개입하여 일시적 강화·약화·이동 경로 생성. 경계 감시단의 분기별 보강 작업에 Lv.5 협력이 필요한 이유. |
| **영기 재구성** | 靈氣再構成 | Lv.5 | 손상된 영기 회로·도관·영문 구조를 원형 수준으로 복원. 5등급 영기 건축의 유지보수 핵심 기술. 인역 전체를 통틀어 가능한 인원이 극소수. |
| **의식 결정 추출** | 意識結晶抽出 | Lv.5 | 고레벨 마수의 의식 결정을 안전하게 추출하는 술식. 미숙한 시도는 결정 파괴 또는 시술자 역침식으로 이어짐. 남원 집거 독점 기술. |
| **영체 고정술** | 靈體固定術 | Lv.5 | 자신 또는 타인의 영체 상태를 안정화하여 소멸을 막는 술식. 예비육체 이식 준비 기간 연장에 필수. 남원 집거와 의선회 소수 보유. |

> ※ Lv.5 술식 중 일부('존재 압력', '영기 도메인')는 발동 의지와 무관하게 항시 작동한다. 이는 Lv.5 존재가 사회에서 격리되는 가장 직접적 이유이며, 일반 인역 사회에서 자유로운 생활이 불가능한 근거다.

## 3. 건축·인프라 — 5등급 영기 건축

기존 건축 설정집(Lv.0~3 범위)에서 별도 문서로 위임된 5등급 영기 건축 체계를 정의한다. 5등급 건축은 기술이 아닌 '인역의 물리적 한계를 다루는 구조물'이며, 운용에 Lv.5 존재의 의식 개입이 필수다.

### 3-1. 5등급 영기 건축 정의

| 항목 | 내용 |
|---|---|
| **정의** | 인역 규모 인프라 또는 차원 경계에 직접 개입하는 영기 건축물. 현재 인역에서 완성된 사례는 역사적으로 5건 미만. |
| **핵심 영문 등급** | 영기 건축(靈氣建築) 등급 영문 — 공간 자체에 영기 법칙을 새기는 방식. 단순 도관망이 아닌 차원 구조에 영향. |
| **운용 조건** | 건설 시: Lv.5 이상 최소 1인의 공간 각인술 및 차원 경계 조작 직접 참여 필수. 유지: Lv.4 이상 상시 배치(의식 선행 법칙). 긴급 보수: Lv.5 참여 필요. |
| **건설 기간** | 소규모(경계 보강 단일 구간): 최소 수개월. 대규모(차원 경계 전진기지): 수년~수십 년. 역사상 최초 5등급 영기 건축(현재력 773년)은 남원 집거·영원 맹약 공동 작업으로 수년 소요. |
| **접근 권한** | 건설 권한: 영원 맹약 공인 필수. 운용 권한: 해당 세력 내부 관리. 무단 5등급 건축 시도는 맹약 최대 위반 사항. |

### 3-2. 5등급 건축물 유형

| 건축물 유형 | 주요 세력 | 기능 및 특성 |
|---|---|---|
| **차원 경계 전진기지** | 경계 감시단 / 영원 맹약 | 경계대 내부에 설치된 고정 방어·감시 거점. 외부 세계 개체 대규모 침투 시 최초 봉쇄선. 경계 안정성 수치를 실시간 측정. |
| **극한 수련 챔버** | 남원 집거 (독점) | Lv.4 이상 수련자를 대상으로 외부 세계 영기 밀도를 모사하는 수련 공간. 집거 외부 공개 불가. 침잠 수련의 핵심 시설. |
| **고밀도 영기 정련로** | 철령원 공사 (독점) | Lv.4~5 소재의 영기를 정제·농축하는 산업 시설. 인역 내 가장 고순도 영기 소재를 생산. 공사 핵심 자산. |
| **영기 대순환 수렴점** | 3대 영원 (자연 구조물) | 중원·남원·북원 영원이 자리한 지점에 자연적으로 형성된 영기 대순환 수렴 구조. 5등급 건축으로 보강·안정화되어 있으며 세 영원의 연결이 끊기면 인역 대순환 자체가 붕괴. |
| **예비육체 보존고** | 남원 집거 / 의선회 | Lv.4 이상 고위 인물의 예비육체를 영기적으로 보존하는 시설. 영체 귀환 시 이식에 사용. 의선회 기술과 집거 5등급 건축의 협업. |

### 3-3. 5등급 건축의 제약

| 제약 유형 | 내용 |
|---|---|
| **의식 선행 법칙** | 모든 5등급 건축물은 Lv.4 이상 상시 운용자가 필요. 자율 운용 불가 — 운용자 부재 시 영기 회로 불안정화 시작. |
| **건설 자원** | 상급 의식 결정 복수 사용 필수. 현재 인역 내 상급 결정 보유량이 극히 희소하여 대규모 5등급 건축은 현실적으로 수십 년에 한 번 가능. |
| **유지보수** | 영기 재구성(Lv.5 술식) 없이는 시간이 지남에 따라 영문 구조 열화. 주요 5등급 건축물의 보수 주기가 인역 정치 일정에 영향을 미침. |
| **세계 부하 연결** | 5등급 건축물이 집중된 구역은 인역의 영기 총량에 직접 영향. Lv.6 가능성이 현실화될수록 기존 5등급 건축의 설계 한계가 노출될 수 있다. |

---

## 4. 소재·생산 체계 — Lv.4~5 전용 소재

고급 영기 소재는 Lv.4~5 기술의 물리적 기반이다. 이 소재들은 단순한 '원자재'가 아닌, 영기와 의식이 물질화된 형태이며 취급 자체에 Lv.4 이상의 역량이 필요하다.

### 4-1. 핵심 소재 명세

| 소재명 | 출처 | 필요 채취 레벨 | 용도 및 특성 |
|---|---|---|---|
| **하급 의식 결정** | Lv.4 마수 (수십 년+) | Lv.4+ 필수 | 명상 챔버 보조 소재, 의식 수련 약재. 고가·희귀 소재이나 Lv.5 결정에 비하면 유통 가능. 규제 대상. |
| **중급 의식 결정** | Lv.4(수백 년+) / Lv.5 초기 | Lv.4+ 필수 | 모의 외부 환경 방 핵심 소재, 고급 수련 장비. 개체 고유 의식 패턴이 결정 내부에 새겨져 있어 수련 효과가 다름. |
| **상급 의식 결정** | Lv.5 (수백 년+) | Lv.5 필수 | 5등급 영기 건축 핵심 소재, 차원 경계 탐사 장비. 인역 전체에 수십 개 이하로 추정. 각 세력이 극비 보관. |
| **외부 세계 원소재** | 외부 세계 (탐사 연합) | Lv.4 탐사대 | 외부 세계 고유 영기 속성을 가진 원료. 인역 영기공학으로 가공 시 독특한 효과. 불법 밀수 경로(무흔)와 공식 경로(탐사 연합) 병존. |
| **침잠 영기석** | 남원 영원 (남원 집거) | Lv.3 이상 감별 | 남원 영원의 침잠 속성 영기가 농축된 천연 결정. Lv.4~5 의식 수련 약재로 최고급. 집거 독점 통제. |
| **경계 파편** | 차원 경계 균열 지점 | Lv.4+ (현장 채취) | 차원 경계가 약화된 지점에서 채취되는 물질화된 경계 잔편. 차원 경계 인지술 강화 소재. 채취 자체가 위험 작업. |

### 4-2. 소재 접근 불평등 구조

Lv.4~5 소재는 단순히 가격이 높은 것이 아니라, 접근 자체가 세력 소속과 레벨에 의해 제한된다. 이 구조가 인역 내 권력 불평등의 물적 기반이다.

| 접근 계층 | 접근 가능 소재 | 구조적 이유 |
|---|---|---|
| **3대 대세력 고위** | 상급 의식 결정 포함 전체 | 채취·보관·이식 모든 권한 보유. 상급 결정은 세력 기밀 자산으로 외부 거래 없음. |
| **탐사 연합 Lv.4** | 외부 세계 원소재, 경계 파편 | 현장 접근권 보유. 의식 결정은 채취하지 않고 고객(세력)에 납품. 중개 이익 구조. |
| **무흔 네트워크** | 하~중급 의식 결정 (비공식) | 공식 규제 우회 경로. 세력 외 Lv.4 수련자에게 유일한 조달 루트인 경우 多. 품질 보증 없음. |
| **독립 Lv.4 개인** | 사실상 접근 불가 | 세력 비소속 Lv.4는 합법적 고급 소재 조달 경로가 없음. 이것이 세력 종속성의 구조적 원인. |

---

## 5. 영체·의식 결정 메커니즘

Lv.4 이상의 존재는 '죽음'의 의미가 달라진다. 육체 소멸이 곧 존재의 소멸이 아니며, 영체 잔존과 예비육체 이식이라는 경로를 통해 사망이 '일시적 상태'가 될 수 있다. 이 메커니즘이 Lv.4~5 존재의 사회적 위치와 서사적 의미를 바꾼다.

### 5-1. 영체 잔존 및 귀환

| 단계 | 내용 |
|---|---|
| **1. 육체 소멸** | Lv.4 이상 존재가 사망 시 육체는 소멸하나 의식·영기 구조가 영체 형태로 잔존. 잔존 가능 기간: Lv.4 수일~수개월, Lv.5 수년~수십 년. |
| **2. 영체 이동** | 영체 상태로 물리적 이동 가능. 속도 느림. 영기 소모 지속. 침식 영기에 취약 — 외부 세계에서 영체 상태 장기 체류 시 오염 위험. |
| **3. 귀환 조건** | 인역 내 사전 준비된 예비육체(豫備肉體) 필요. 예비육체는 의선회·남원 집거 협업으로 제작. 고급 소재 대량 소모. 제작 기간 수개월~수년. |
| **4. 이식 절차** | 영체가 예비육체에 깃들어 부활. Lv.4 이상 의술사 복수 참여 필수. 이식 성공률은 영체 손상도에 따라 차이. 기억 일부 소실 가능. |
| **5. 이식 후 상태** | 육체 회복 기간 필요. 일부 개체는 이식 후 레벨 일시 저하 경험. 드물게 이식된 예비육체와 영체의 적합성 문제로 인격 변화 보고됨. |

> ※ 예비육체는 세력 자산이기도 하다. Lv.5 극한자의 예비육체를 보유한다는 것은 그 세력이 해당 Lv.5 존재의 '재생산'을 통제한다는 의미다. 이 구조가 Lv.5 존재가 세력에 종속되는 실질적 이유다.

### 5-2. 의식 결정 등급 체계

| 등급 | 출처 | 의식 특성 | 주요 용도 |
|---|---|---|---|
| **하급 의식 결정** | Lv.4 마수 (수십 년+) | 의식 농도 낮음. 서식 환경 영기 속성 단순 반영 | 명상 챔버 보조 소재, 의식 수련 약재. 가장 많이 유통되는 의식 결정이나 여전히 고가·희귀. |
| **중급 의식 결정** | Lv.4(수백 년+) / Lv.5 초기 | 개체 고유 의식 패턴이 새겨짐 | 모의 외부 환경 방 핵심 소재, 고급 수련 장비. 결정 내 패턴이 수련 효과에 차별적 영향. |
| **상급 의식 결정** | Lv.5 (수백 년+) | 결정 내부에서 독자적 영기 흐름 발생 | 5등급 영기 건축 핵심 소재, 차원 경계 탐사 장비. 인역 전체에 수십 개 미만. 각 세력 최고 기밀 자산. |
| **침식 잔편** | 완전 침식 개체 | 침식 영기 오염. 불안정 | 침식 저항 약재, 역방향 연구 소재. 위험 등급 분류. 취급 시 감별 의술사 동반 필수. |

## 6. 외부 세계 운용 기술

외부 세계 탐사·전투·귀환은 Lv.4 이상에게만 공인되는 활동이다. 이 영역의 기술은 인역 내 기술과 별도의 체계를 갖추며, 탐사 연합이 가장 많은 실용 노하우를 보유한다.

### 6-1. 외부 세계 진입 표준 절차

| 단계 | 작업 | 기술 상세 |
|---|---|---|
| **1** | 사전 의식 결정 복용 | 하~중급 의식 결정을 영기적으로 흡수. 외부 세계 영기 밀도에 대한 의식 내성 일시 증가. 효과 지속 수시간~수일. |
| **2** | 의식 방어막 설치 | 외부 세계 진입 전 반드시 시전. 외부 세계의 영기 정보 오염 경로를 차단. 지속 유지에 영기 소모. |
| **3** | 차원 경계 인지 활성화 | 경계 통과 지점을 탐지. 일반적으로 탐사 연합이 사전에 매핑한 안정 통과점을 사용. 불안정 구간 통과 시 경계 부하 발생. |
| **4** | 팀 구성 최종 확인 | Lv.4 최소 2인 (단독 진입 원칙적 금지). 역할 분담: 전투·탐사·귀환 경로 유지. 통신 술식 동기화. |
| **5** | 귀환 기점 영기 각인 | 진입 지점에 귀환용 영기 표식을 각인. 이 표식이 소멸하면 귀환 경로 상실. 외부 세계 장기 체류 시 표식 갱신 필수. |

### 6-2. 외부 세계 전투 특성

| 상황 | 기술 및 대응 |
|---|---|
| **고밀도 영기 환경** | 인역 대비 영기 밀도가 수배 이상. 영기 회로 과부하 방지를 위해 조작량 제한 필요. 반대로 영기 공급은 풍부하므로 소모 전략이 유리. |
| **외부 세계 개체** | Lv.5에 준하는 외부 개체 존재 확인됨(경계 붕괴 7일 기록). 의식 구조가 인역 존재와 달라 의식 방어막 우선 — 정신 공격 패턴이 인역 내 침식종과 다름. |
| **철수 기준** | 팀 구성원 중 1인이라도 의식 방어막 붕괴 시 즉시 철수. 의식 손상은 영체 손상으로 이어지며 인역 귀환 후 회복 불가 케이스 보고됨. |
| **Lv.5 단독 운용** | Lv.5는 외부 세계에서 단독 장기 체류 가능 — 존재 압력이 외부 개체에도 억제 효과. 단, 세계 부하 임계 가능성으로 장기 활동에 제약. |

---

## 7. 세력별 Lv.4~5 기술 독점 구조

Lv.4~5 기술은 모든 세력에게 균등하게 분포되어 있지 않다. 특정 기술은 특정 세력이 사실상 독점하며, 이 기술 불균형이 인역 권력 구조의 물적 토대를 이룬다.

| 세력 | 독점 기술·자산 | 구조적 의미 |
|---|---|---|
| **남원 집거** | 의식 결정 추출술, 극한 수련 챔버, 예비육체 보존 | Lv.4~5 '탄생'과 '재생'을 통제. 누가 경계인이 되고 극한자가 '죽지 않을' 수 있는지를 집거가 결정. 레벨 인증 권위와 결합 시 인역 최고의 실질 권력. |
| **철령원 공사** | 고밀도 영기 정련로, 4~5등급 영문 설계 도면 | 고급 소재 '가공'을 독점. 원료가 있어도 정련 없이는 사용 불가한 소재가 다수. 5등급 건축 필요 부품의 최대 공급처. |
| **영역 탐사 연합** | 외부 세계 탐사 기술, 경계 통과점 데이터 | 외부 세계 '진입'을 사실상 통제. 공인 탐사 경로와 비공식 경로 모두 연합의 실질 파악 하에 있음. 상급 의식 결정의 최대 공급원. |
| **녹령수호단** | Lv.4~5 마수 공생 기술, 침잠 영기석 원산지 통제 | 수련 핵심 소재의 원천 통제. 마수 장로와의 공생 관계로 의식 결정 자연 발생 구역 독점 관리. |
| **무흔** | 비공식 소재 유통, 제약 없는 실험적 영기공학 | 공식 체계 외의 Lv.4~5 기술 '우회 접근' 제공. 세력 외 경계인에게 유일한 고급 소재 경로. 기술 공유가 역설적으로 독점 구조 균열의 씨앗. |
| **영기 의선회** | 영체 손상 감별, 예비육체 이식 시술, 침식 억제 | Lv.4~5 존재의 '유지'를 담당. 중립을 표방하지만 이식 시술 독점이 사실상 집거·의선회 공동의 고레벨 인사 관리 체계를 구성. |

---

## 8. 한계·실패·부작용

Lv.4~5 기술은 강력하지만 실패 시 대가가 크다. 이 위험성이 현실감을 부여하고, 세력이 고레벨 인원을 '자산'처럼 통제하는 구조적 이유가 된다.

### 8-1. 술식 실패 유형

| 실패 유형 | 발생 조건 | 결과 |
|---|---|---|
| **술식 폭주** | 고밀도 영기 압축 과부하 | 압축 임계 초과 시 역방향 폭발. 반경 내 아군 포함 대규모 피해. 인역 내 기록된 사고 중 규모 상위 사례 다수가 Lv.4 술식 폭주. |
| **의식 역류** | 외부 세계 영기 흡수 중 방어막 붕괴 | 흡수한 외부 영기가 시술자 의식으로 역류. 경미한 경우 일시적 인식 오류. 심각한 경우 영구적 의식 손상 또는 침식 1단계 진입. |
| **영체 분리 과다** | 영체 분리 공격 장시간 유지 | 분리된 영체 회수 실패 시 본체와 단절. 본체는 식물 상태, 영체는 소멸 위험. 회수 가능 시간대가 엄격히 제한됨. |
| **공간 각인 붕괴** | 5등급 건축 운용자 의식 단절 | 운용자 사망 또는 의식 단절 시 각인 구조 급속 불안정화. 차원 경계 시설의 경우 외부 영기 유입 즉시 시작. |

### 8-2. 고레벨 수련의 구조적 위험

| 위험 유형 | 내용 |
|---|---|
| **존재 고립** | Lv.5 이상 수련 심화 시 존재 압력이 강해져 타인과의 자연스러운 접촉이 점점 불가. 사회적 고립 불가피. 일부 극한자는 인역 내에서 완전 격리된 상태로 생존. |
| **세계 부하 임계** | 현재력 810년대 기준, 인역이 처음으로 Lv.6 수용 가능 임계에 근접. Lv.5 수련자 복수의 동시 상위 수련은 수용 한계 법칙과 직접 충돌. |
| **침식 감별 오류** | 외부 세계 장기 탐사 후 귀환한 Lv.4 존재는 침식 초기 증상과 수련 심화 증상이 유사. 잘못 진단 시 불필요한 격리 또는 실제 침식 방치. |
| **예비육체 부적합** | 이식한 예비육체와 귀환 영체의 영기 속성 불일치 시 부분적 인격 변화 또는 레벨 저하. 드물게 육체가 영체를 '거부'하는 사례 보고. |

> ※ Lv.5 존재의 죽음은 단순한 생명 손실이 아니다. 세력의 5등급 건축 운용 능력 상실, 상급 의식 결정 공급원 소멸, 세계 부하 계산 재조정 등 문명적 차원의 파장이 따른다. 이것이 각 세력이 극한자를 '전력'이 아닌 '인프라'로 취급하는 이유다.

## 설정집 정합성 메모

이 설정집은 세계관 설정집 v4 완전 정합이다.

**6대 법칙과의 연결:**
- 제2법칙 (의식 선행): 모든 Lv.4~5 기술은 운용자 의식 개입이 명시됨. 5등급 건축 운용자 상시 배치 조건이 이 법칙의 직접 적용.

- 제6법칙 (존재 이행): 의식 결정 형성, 영체 잔존, 예비육체 이식이 이 법칙의 물적 표현.
