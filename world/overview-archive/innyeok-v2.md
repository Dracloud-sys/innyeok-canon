# 인역(人域) 세계관 설정집 v2

## 1. 인역의 공간적 정의

인역(人域)은 외부 세계와 구분된 **독립된 물리적 차원**이다. 외부 세계가 단일 생명체만으로도 인역 전체의 영기 총량에 필적하거나 초월하는 존재들이 활보하는 영기 포화 공간이라면, 인역은 그러한 외부의 압도적 영기밀도로부터 차단된, 인간 문명이 자생적으로 성립할 수 있는 **저영기(低靈氣) 안정 구역**이다.

인역의 경계는 자연적으로 형성된 것인지, 혹은 고대의 어떤 존재에 의해 구획된 것인지 현재 문명 수준에서 규명되지 않는다. 다만 경계 너머로는 영기의 밀도와 성질이 급격히 달라지며, 일반 인간이 그 변화에 노출될 경우 정보 습득 장애, 인식 오류, 정신 침식 등의 증상이 발생한다.

### 1-1. 인역의 수용 한계

인역이 안정적으로 수용할 수 있는 존재의 규모는 고정되어 있지 않으며, **영기 총량**과 **차원 경계 안정성** 두 축의 곱으로 결정된다.

- **영기 총량**: 인역 전체에 순환하는 영기의 절대량. 영기공학 인프라 확장, 영원(靈源) 개발, 인구 및 생태계 성장에 따라 점진적으로 증가한다.
- **차원 경계 안정성**: 인역을 외부 세계로부터 격리하는 경계 구조의 견고함. 영기 건축(5등급 영문 구조물) 및 차원 경계 유지 연구가 이 수치에 영향을 미친다.

현재 인역은 영기공학의 지속적 발전에 따라 **수용 한계가 서서히 상승하는 중**이다. Lv.6 개체는 역사상 전례가 없으며, 인역 문명은 지금 그 문턱에 처음으로 접근하고 있다.

## 2. 영기(靈氣)의 성질

영기는 인역의 기반 에너지이자 물질, 의식, 생명 현상 모두에 걸쳐 작용하는 **독자적 개념의 힘**이다.

### 2-1. 영기의 주요 성질

- **편재성**: 인역 내 공간에 희박하게 존재하며, 생명체·물질·환경 모두에 침투 가능
- **축적성**: 생명체는 신체 내에 영기를 축적할 수 있으며, 의식 수준과 육체적 단련을 통해 축적량을 늘릴 수 있음
- **의식 연동성**: 영기는 의식에 의해 움직임. 의식 수준이 높을수록 같은 양의 영기를 더 정밀하고 효율적으로 운용 가능
- **조형성**: 특정 문양이나 회로 구조에 영기를 주입하면 지속적·자율적 작동이 가능한 구조물을 만들 수 있음
- **불완전 자동화 한계**: 영기를 지속 주입받더라도 구조물은 **사전에 설계된 패턴 내에서만** 작동하며, 상황 판단·학습·창의적 대응은 불가능

## 3. 영기 기반 문명 체계 (영기공학)

| 현실 기술 | 인역 대응 기술 |
|---|---|
| 전기 배선·회로 | 영기 도관·영기 회로 |
| 연료 엔진 | 영기 주입식 동력로 |
| 컴퓨터·자동화 | 영문 구조물 (패턴 기반, 부분 자동화) |
| 통신망 | 영기 공명 결정 네트워크 |
| 의학 | 영기 순환 의술·육체 수준 강화 시술 |

### 영문 구조물 등급

| 등급 | 기능 수준 | 제작 최소 레벨 |
|---|---|---|
| 1등급 (단문) | 단일 반복 동작 | Lv.1 |
| 2등급 (복합문) | 조건 분기 포함 2~3단계 | Lv.2 |
| 3등급 (연쇄문) | 복수 트리거·피드백 루프 | Lv.3 |
| 4등급 (대형 회로) | 건물·설비 규모 통합 시스템 | Lv.4 |
| 5등급 (영기 건축) | 인역 규모 인프라, 차원 경계 관련 | Lv.5 |

## 4. 레벨 시스템

레벨은 **영기 축적량 · 육체 수준 · 의식 수준** 세 축의 종합 평가치. 세 축이 균형 있게 성장해야 다음 레벨 진입 가능.

| 레벨 | 명칭 | 주요 특성 |
|---|---|---|
| Lv.0 | 범인(凡人) | 영기를 감지하거나 다루지 못하는 일반인 |
| Lv.1 | 각성자(覺醒者) | 영기 감지·미량 조작 가능. 기초 영문 각인 수행 |
| Lv.2 | 수련자(修鍊者) | 영기 축적 안정화. 복합 영문 제작, 단거리 탐지 |
| Lv.3 | 숙련자(熟鍊者) | 영기 조작 범위·정밀도 향상. 인역 내 탐사·전투 가능 |
| Lv.4 | 경계인(境界人) | 인역-외부 경계 인식. 외부 세계 탐사 자격. 사후 영체 잔존 |
| Lv.5 | 극한자(極限者) | 인류 종의 한계치. 외부 세계 단독 활동 가능. 극소수 |
| Lv.6 | 존재론적 상승 (이론) | 존재 방식의 질적 전환. 역사상 전례 없음. 차원 균형에 직접 간섭 |

**Lv.5→Lv.6**: 수치의 극점을 넘는 순간 존재 방식 자체가 바뀌는 질적 전환. 더 강해지는 것이 아니라 다른 무언가가 되는 것.

## 5. 사후 영체와 부활 메커니즘

- Lv.4 이상 개체는 사망 시 **영체(靈體)가 잔존**
- 인역 귀환 후 **예비육체**에 깃들어 부활 가능
- 부활 후 영기 축적량·육체 수준은 초기화, 의식 수준은 부분 보존

### 영체 손상과 기억 손실

| 손상 등급 | 기억 손실 | 레벨 회복 전망 |
|---|---|---|
| 경미 (10% 미만) | 단기 기억 일부 | 원래 레벨의 80~90% |
| 중간 (10~40%) | 수 개월~수 년 소실 | 원래 레벨의 50~70% |
| 중대 (40~70%) | 수십 년 단위 손실, 인격 변화 가능 | 30~50%, 일부 상한선 하락 |
| 심각 (70~99%) | 거의 모든 서술적 기억 소실 | 사실상 새로운 개체. Lv.1 재시작 |
| 완전 소멸 (100%) | 부활 불가. 영구 사망 | — |

## 6. 외부 세계와의 관계

- 외부 세계: 영기가 극도로 농밀한 공간. 자생 개체 대부분은 Lv.6 이상의 존재 방식
- 외부 탐사는 **Lv.4 이상** 조건 (의식 수준 미달 시 정신 침식, Lv.3 이하는 즉사에 가까움)
- 탐사 목적: 영기 자원 획득, 차원 경계 점검, 외부 개체 감시, 수련

## 7. 생태계

### 생명체 분류

| 분류 | 설명 |
|---|---|
| 영기 비의존종 | 영기를 거의 사용하지 않는 일반 동식물 |
| 영기 감응종 | 미량의 영기를 흡수·방출하는 생물 |
| 영기 보유종 | 신체 내 영기를 의도적으로 축적·활용하는 생물 (인간, 마수 포함) |
| 영기 침식종 | 외부 세계 영향으로 변질된 생물. 인역 내 이변의 징후 |

### 인간의 동급 최강 근거

같은 레벨의 타 생명체 대비 **전투 기술·도구 활용·영기 밀도 및 순도** 총합에서 우위. (단, 인역 내에서만 적용)

### 마수 특성

| 구분 | 영기 총량 | 의식 수준 | 특징 |
|---|---|---|---|
| 일반 야수 | 낮음 | 낮음 | 본능적·비효율적 영기 사용 |
| 마수 (저~중레벨) | 중간 | 낮~중간 | 종별 특화. 단일 능력은 강할 수 있음 |
| 마수 (고레벨 Lv.4~5) | 높음 | 인간에 준함 | 극소수. 인간과 거의 동일한 사고 가능 |
| 인간 | 중간 | 높음 | 기술·도구·영기 순도로 동급 최강 |
| 영기 침식종 | 비정상적 높음 | 붕괴·왜곡 | 제어 불가. Lv.4 이하=자원, Lv.5 이상=재해 |

### 영원(靈源)

영기 맥(靈氣脈)이 집중된 지점. 대형 도시·시설의 상당수가 영원을 중심으로 건설됨.

## 8. 사회 구조

### 레벨별 사회적 역할

- **Lv.0~1**: 일반 시민. 영기공학 설비의 수혜자
- **Lv.2~3**: 영기공학 기술자, 술사, 영기 의술사, 경비 병력
- **Lv.4**: 외부 세계 탐사 자격. 국가·조직 차원 특수 임무 담당
- **Lv.5**: 인역 문명 전체 극소수. 사실상 국가급 전력

### 인류 자격 제도

인간과 동등한 의식 수준을 보유한 타 종족·개체에게 부여하는 사회 구성원 자격. 명문화된 제도가 아닌 **관습**으로 운영됨. 고레벨 마수가 이 경로로 사회 편입된 사례 존재. 판정 일관성 미보장 → 사회 갈등의 잠재적 원천.
