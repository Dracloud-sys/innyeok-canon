## 결정

`world/overview.md` §13-1의 Lv.0~1 "영기 자체를 직접 운용하는 능력은
없다"는 서술은 설비의 영기·회로·설정에 직접 개입하는 기술 행위를
독립 수행할 능력이나 자격이 없다는 뜻이다. 안전 범위가 고정된 일상 사용과
각 경지가 실제로 충족하는 낮은 등급의 기술 행위를 함께 금지한다는 뜻이
아니다.

Lv.0도 허가된 보호 인터페이스에서 사전 설정 동작을 호출할 수 있다.
봉인된 정상 규격 축령정을 운반하거나 보호된 규격 슬롯에 물리적으로
교체하는 행위도 가능하다. 회로·설정 변경, 영기 직접 주입, 봉인 해제,
손상·누출·비규격 축령정 취급은 일상 보호 사용에 포함되지 않는다.

## 행위 구분

| 행위 | 판정 경계 |
|---|---|
| 일상 보호 사용 | 사전 설정된 안전 동작 호출. 영기·회로·설정에 직접 개입하지 않음 |
| 기술적 활성화 | 정해진 절차에 따라 영기를 연결·주입하거나 설비를 기동·정지 |
| 기술적 운전 | 작동 상태를 읽고 허용 범위에서 출력·동작 변수를 조정 |
| 점검 | 상태와 결함을 판별하며 설계를 변경하지 않음 |
| 유지보수 | 소모품 교체·조정·예방 작업으로 정상 상태를 유지 |
| 수리 | 손상된 설비를 승인된 설계 상태로 복구 |
| 설계 | 새로운 영문 패턴·회로와 동작 규칙을 결정 |
| 제작·각인 | 설계를 물질에 구현해 새 영문 또는 회로를 생성 |

## 등급별 최저 경지

| 설비 등급 | 기술적 활성화·운전·점검·유지보수·수리 | 독립 신규 설계·제작·각인 |
|---|---:|---:|
| 1등급 | Lv.1 | Lv.1 |
| 2등급 | Lv.1 | Lv.2 |
| 3등급 | Lv.2 | Lv.3 |
| 4등급 | Lv.3 | Lv.4 |
| 5등급 | Lv.4 | Lv.5 |

이 표는 능력의 정사상 최저선이다. 법적 자격, 소유자 허가, 현장 규정,
설비 상태와 위험도는 요구 경지를 높이거나 추가 인원을 요구할 수 있다.
그 조건으로 표의 최저선을 낮출 수 없다. 고등급 설비의 보호된 사용자
기능에도 별도의 허가와 현장 제한을 둘 수 있다.

## 기존 문서와의 관계

이 결정은 `world/overview.md` §4-2의 제작 최소 경지와 "운용은 제작보다
한 단계 낮다"는 원칙을 행위별로 명확화한다. `world/labor.md`와
`world/architecture.md`의 직종·현장별 요구 조건은 이 최저선 위에 법적·안전
요건을 더한 것으로 읽는다. Lv.0의 봉인된 정상 규격품 운반·교체는 기술적
충전·주입·점검·수리와 구분한다.
